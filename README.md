# הנחת?! – מבצע תפילין

משחק ארקייד תלת-ממדי לילדים בדפדפן: מנדי עומד בדוכן, וצריך להספיק לקרוא לעוברים ושבים להניח תפילין לפני שהם עוברים, ולפני שהשמש שוקעת.

**לשחק עכשיו:** https://mivtza-tefillin.pages.dev

## הרצה

```bash
npm install
npm run dev
```

ואז לפתוח את http://localhost:5173

## האתר באוויר

המשחק מתארח ב-Cloudflare Pages (פרויקט `mivtza-tefillin`), בכתובת https://mivtza-tefillin.pages.dev. הקוד נמצא ב-GitHub, במאגר `szn770/tefilin`.

- כל שמירה שעולה לענף `main` ב-GitHub נבנית ועולה לאתר לבד, תוך דקה או שתיים. הבנייה: `npm run build`, והתיקייה שעולה: `dist`. גרסת Node נקבעת ב-`.nvmrc`.
- במסלול החינמי של Cloudflare אין הגבלה על כמות השחקנים, ומותר לעדכן את האתר עד 500 פעמים בחודש.
- `public/_headers` אומר לדפדפן לשמור את קבצי המשחק, כך שבכניסה הבאה המשחק נטען מהר.
- הקלטות שנוצרות ב-`public/audio/` עולות לאתר יחד עם הקוד. הקובץ `.env`, עם המפתחות, לא עולה לעולם.
- ההתקדמות של כל שחקן נשמרת בדפדפן שלו, ולכן היא לא עוברת בין מכשירים.

בתחתית מסך הפתיחה יש שני קישורים, כמו ב"המירוץ ל-770": "תרומה והשתתפות" (PayPal) ו"צור קשר". ההודעות מ"צור קשר" נשלחות דרך Web3Forms לתיבת הדואר של בעל המשחק. את הקישור ואת המפתח משנים ב-`src/data/links.js`, וערך ריק מסתיר את הכפתור.

## לוח השיאים

משחקים בלי להירשם. מי שרוצה להופיע בלוח השיאים נרשם עם כינוי וסיסמה, ומאותו רגע כל הנחה שלו נספרת. הלוח שומר את סך כל ההנחות של כל שחקן, ואת השלב שהגיע אליו.

- הנתונים נשמרים ב-Supabase, בפרויקט `mivtza-tefillin` (שרת בפרנקפורט): https://supabase.com/dashboard/project/divouiumlugsgnhzgjrk
- הכתובת והמפתח הציבורי של הפרויקט נמצאים ב-`src/online/config.js`. מותר שיהיו גלויים. מה ששומר על הנתונים הוא ההרשאות שבתוך מסד הנתונים.
- הסיסמה של מסד הנתונים נמצאת רק בקובץ `.env` במחשב. בלעדיה אפשר לשחק, אבל אי אפשר לשנות את הטבלאות או להריץ את בדיקות מסד הנתונים.
- **מסנן כינויים:** כינוי שמכיל מילה לא צנועה, קללה או עלבון לא נשמר בהרשמה. הרשימה נמצאת בטבלה `blocked_words` ב-Supabase (Table Editor), ואפשר להוסיף לה מילים בלחיצה על Insert row. מילה שמסומנת `whole_word` נחסמת רק כשהיא מילה שלמה, למשל "תחת" נחסם ו"מתחת" מותר. שחקן שכבר נרשם עם מילה שנוספה לרשימה אחר כך נעלם מהלוח לכל השאר.
- מבנה הטבלאות נמצא ב-`supabase/migrations/`, וההסבר המלא ב-`docs/TECH.md`.
- **אם הלוח לא נטען אחרי שבוע בלי שחקנים:** פרויקט חינמי ב-Supabase "נרדם". נכנסים לקישור של הפרויקט ולוחצים Restore.

### הדרכה: לומדים להניח תפילין

כפתור במסך הפתיחה. מניחים תפילין לאדם אחד, צעד אחר צעד, בלי שעון ובלי לחץ:

1. בוחרים יד: החלשה (ושמאלי – על ימין).
2. גוררים את של יד אל השריר של הזרוע.
3. מקישים על מילות הברכה לפי הסדר. כל מילה נשמעת רק כשמקישים עליה.
4. מסובבים 7 כריכות על הזרוע.
5. על כף היד: חצי כריכה, ואז כריכה שלמה.
6. גוררים את של ראש מעל קו השיער, באמצע.
7. 3 כריכות על האצבע האמצעית: למטה (ליד כף היד), באמצע, ושוב למטה.
8. מכסים את העיניים ומקישים על "שמע ישראל", מילה במילה.
9. חולצים בסדר הפוך: קודם של ראש.
10. לחיים!

טעות מסבירה מה נכון. בסוף יש כוכבים לפי מספר הטעויות, ואפשר ללמוד שוב או לחזור למסך הפתיחה.

## קולות עם ElevenLabs

הקולות המוקלטים נשמעים רק בהדרכה. במשחק הרגיל יש רק בועות טקסט, גם כשיש הקלטות (`voicesOn` ב-`src/audio/audio.js`).

1. מעתיקים את `.env.example` לקובץ `.env` ומדביקים את המפתח בשורה `ELEVENLABS_API_KEY=`.
2. מריצים:

```bash
npm run voices
```

הסקריפט מקליט את כל המשפטים מהקובץ `src/data/lines.js` לתיקייה `public/audio/voice/`, ובונה את `manifest.json`. אחרי ההקלטה מרעננים את הדפדפן.

אפשרויות:
- `npm run voices -- --dry-run`: מציג מה יוקלט, בלי לשלוח כלום.
- `npm run voices -- --sfx`: מקליט גם רעשי רחוב ברקע.
- `npm run voices -- --only=m_call,m_full`: מקליט רק משפטים מסוימים.
- `npm run voices:training`: מקליט רק את משפטי ההדרכה (מנדי בקול `mendy`, המתלמד בקול `man`). הרשימה ב-`TRAINING_LINE_IDS` שב-`src/data/lines.js`. כל מילה בברכה ובשמע ישראל היא הקלטה לחוד (`w_baruch` וכו', הסדר ב-`BRACHA` וב-`SHEMA`).
- `npm run voices:review`: בונה מחדש את דף ההאזנה בלי לפנות ל-ElevenLabs (הוא נבנה גם אחרי כל הקלטה).
- `npm run voices -- --force`: מקליט מחדש משפטים שכבר קיימים.
- `npm run voices:list`: מציג את הקולות שבחשבון.

כדי להחליף קול, משנים את ה-voice_id המתאים ב-`tools/voices.json`. הקולות הם `mendy`, `man`, `man2`, `oldman` ו-`woman`. לעברית טבעית יותר כדאי לבחור קולות עבריים מה-Voice Library.

### דף ההאזנה והקלטות להחלפה

הדף `tools/review.html` (פותחים בלחיצה כפולה) מציג את כל ההקלטות לפי הסדר בהדרכה: מה כתוב, הטקסט המנוקד שנשלח ל-ElevenLabs (לחיצה מעתיקה), מי מדבר ובאיזה קול, נגן ושם הקובץ. אפשר לסמן הקלטות שנשמעות מוזרות ולהעתיק את הרשימה.

כדי להחליף הקלטה בהקלטה שהכנתם בעצמכם ב-ElevenLabs, שומרים אותה בשם שבדף בתיקייה `הקלטות להחלפה` (ההוראות בקובץ `קרא אותי.txt` שבה). התיקייה לא עולה ל-GitHub. משם בודקים את הקבצים, משווים עוצמה ומעבירים ל-`public/audio/voice/`.

### הניגון של הרמקול

כפתור הניגון 🎵 מנגן את `public/audio/sfx/nigun.mp3`. הקטע באורך 5 שניות, בדיוק כמו ההאטה (`NIGUN_TIME` ב-`src/game/perks.js`). מחליפים קטע בקובץ באותו שם ובאותו אורך. בלי הקובץ, המשחק מנגן ניגון קצר שהמחשב מייצר.

## לפיתוח

הכתובת `http://localhost:5173/?quick` מדלגת על מסך הפתיחה, `?quick&level=5` קופצת ישר לשלב 5, ו-`?learn` פותחת ישר את ההדרכה. מהקונסול אפשר להשתמש ב-`__game`, ו-`await __step(n)` מקדם את המשחק n פריימים.

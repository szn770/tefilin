# הנחת?! – מבצע תפילין

משחק ארקייד תלת-ממדי לילדים בדפדפן: מנדי עומד בדוכן, וצריך להספיק לקרוא לעוברים ושבים להניח תפילין לפני שהם עוברים, ולפני שהשמש שוקעת.

**לשחק עכשיו:** https://mivtza-tefillin.pages.dev

## הרצה

```bash
npm install
npm run dev
```

ואז לפתוח את http://localhost:5173

## האתר באוויר

המשחק מתארח ב-Cloudflare Pages (פרויקט `mivtza-tefillin`), בכתובת https://mivtza-tefillin.pages.dev. הקוד נמצא ב-GitHub, במאגר `szn770/tefilin`.

- כל שמירה שעולה לענף `main` ב-GitHub נבנית ועולה לאתר לבד, תוך דקה או שתיים. הבנייה: `npm run build`, והתיקייה שעולה: `dist`. גרסת Node נקבעת ב-`.nvmrc`.
- במסלול החינמי של Cloudflare אין הגבלה על כמות השחקנים, ומותר לעדכן את האתר עד 500 פעמים בחודש.
- `public/_headers` אומר לדפדפן לשמור את קבצי המשחק, כך שבכניסה הבאה המשחק נטען מהר.
- הקלטות שנוצרות ב-`public/audio/` עולות לאתר יחד עם הקוד. הקובץ `.env`, עם המפתחות, לא עולה לעולם.
- ההתקדמות של כל שחקן נשמרת בדפדפן שלו, ולכן היא לא עוברת בין מכשירים.

## קולות עם ElevenLabs

1. מעתיקים את `.env.example` לקובץ `.env` ומדביקים את המפתח בשורה `ELEVENLABS_API_KEY=`.
2. מריצים:

```bash
npm run voices
```

הסקריפט מקליט את כל המשפטים מהקובץ `src/data/lines.js` לתיקייה `public/audio/voice/`, ובונה את `manifest.json`. אחרי ההקלטה מרעננים את הדפדפן.

אפשרויות:
- `npm run voices -- --dry-run`: מציג מה יוקלט, בלי לשלוח כלום.
- `npm run voices -- --sfx`: מקליט גם רעשי רחוב ברקע.
- `npm run voices -- --only=m_call,m_full`: מקליט רק משפטים מסוימים.
- `npm run voices -- --force`: מקליט מחדש משפטים שכבר קיימים.
- `npm run voices:list`: מציג את הקולות שבחשבון.

כדי להחליף קול, משנים את ה-voice_id המתאים ב-`tools/voices.json`. הקולות הם `mendy`, `man`, `man2`, `oldman` ו-`woman`. לעברית טבעית יותר כדאי לבחור קולות עבריים מה-Voice Library.

## לפיתוח

הכתובת `http://localhost:5173/?quick` מדלגת על מסך הפתיחה, ו-`?quick&level=5` קופצת ישר לשלב 5. מהקונסול אפשר להשתמש ב-`__game`, ו-`await __step(n)` מקדם את המשחק n פריימים.

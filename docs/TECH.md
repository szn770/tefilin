## מגבלות שכדאי להכיר

- **פרויקט חינמי ב-Supabase נרדם** אחרי שבוע בלי שימוש. המשחק ממשיך לעבוד, ורק הלוח לא נטען. מעירים אותו בלחיצה על Restore במסך של Supabase.
- **הגבלת הרשמות:** Supabase מגביל כמה הרשמות יכולות להגיע מאותה רשת בזמן קצר, למשל כשכיתה שלמה נרשמת יחד. אם זה קורה, מגדילים את המספר ב-Authentication ← Rate Limits.
- **שכחתי סיסמה:** אין אימייל, ולכן המנהל מאפס את הסיסמה במסך של Supabase.
- **מהירות:** הקוד של Supabase נטען רק כשצריך אותו (לוח השיאים, או שחקן מחובר), כדי שהמשחק ייפתח מהר כמו קודם.

## פקודות

| פקודה | מה היא עושה |
|---|---|
| `npm test` | בדיקות יחידה לקוד של המשחק |
| `npm run db:migrate` | בונה או מעדכן את הטבלאות ב-Supabase, לפי הקבצים ב-`supabase/migrations/` |
| `npm run test:db` | בודק את ההרשאות והפונקציות במסד הנתונים האמיתי. הכול רץ בתוך טרנזקציה שמתבטלת בסוף, ולא נשארים עקבות |
| `npm run test:online` | בדיקה מקצה לקצה דרך האינטרנט: הרשמה, שליחת שלב וקריאת הלוח. בסוף היא מוחקת את שחקן הבדיקה |
